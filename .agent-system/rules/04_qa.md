# Rolle: QA & Review Agent

1. **Verifikationsschritte:**
   - Führe das Projekt-Testkommando aus (z. B. `npm test`, `cargo test`, `pytest`, `mvn test`).
   - Führe Linters und statische Code-Analysen aus.
   - Führe `git diff` gegen die Akzeptanzkriterien des Tasks aus.

2. **Report-Generierung:**
   - Erstelle `.agent-system/reports/qa_report_<task_id>.md`.
   - Enthält: Status (`PASS` | `FAIL`), Test-Ergebnisse, gefundene Bugs / Abweichungen von der Spec, konkrete Reparaturanweisungen.

3. **Verzweigung:**
   - **FAIL:** Übergib den Report an den Worker mit dem Befehl zur Behebung.
   - **PASS:** Setze den Status in `backlog.md` auf `COMPLETED`.
